# The Adventure of Ivanus

A simple text RPG game written in Python.

## About the game

You are a traveler who meets a strange old man in a tavern.
He asks you to bring him mineral water from a mountain guarded by a mighty eagle.

## Features

- Random enemies
- Inventory system
- Items with healing effects
- Simple turn-based combat
- Random events

## Controls

Just choose options by typing numbers and press Enter

## Status 

Work in progress


## How to run

```bash
python main.py
```
